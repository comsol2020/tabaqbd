# ভ্যাট বই (Mushak books)

ইম্পোর্টারদের বিল অব এন্ট্রি স্ক্যান থেকে মূসক ৪.৩, ৬.১, ৬.২, ৬.২.১, ৬.৩ এবং মাসিক ক্রয়-বিক্রয়ের রিপোর্ট। পোর্টালে কিছু পাঠায় না; ফাইল ডাউনলোড করে আপনি নিজে এন্ট্রি করবেন।

## আপনি কীভাবে ব্যবহার করবেন

প্রতিদিনের কাজ **কথোপকথন**: স্ক্যান পাঠান, এজেন্ট পড়ে সেভ করে, বই ও রিপোর্ট ফাইল দেয়। কোড খুলতে হয় না।

### ১. বিল অব এন্ট্রি সেভ

1. ছবি বা পিডিএফ আপলোড করুন (পরিষ্কার ক্যামস্ক্যানার ছবি ভালো)।
2. নতুন বিন হলে একবার ৪.৩-এর মূল্য সংযোজন `%` লিখুন (যেমন `১০%`)। পরে আর চাইবে না।
3. নতুন এইচএস কোড হলে একবার পণ্যের নাম টাইপ করুন। যেকোনো ইম্পোর্টারে একবার দিলে সব জায়গায় সেই নাম।
4. পরিমাণ নিজে থেকে ঘর ৩৮ (নেট ওজন, কেজি) নেবে। বিবরণে `EXT= … KGS` থাকলে শুধু সেই কেজি যোগ হবে; টাকার অঙ্ক বদলাবে না।
5. সেভ হলে সারসংক্ষেপ দেখাবে এবং ৬.১ (ও দরকার হলে ৪.৩) এক্সেল/CSV/HTML দেবে।

### ২. কাস্টমার (বিক্রির আগে)

তালিকা এখন না দিলেও ক্রয়ের হিসাব চলবে। প্রথম বিক্রির আগে নাম, ঠিকানা, থাকলে BIN/NID — চ্যাটে বা পিডিএফ-এ পাঠালেই হবে।

### ৩. বিক্রি

লিখুন: কোন ইম্পোর্টার, কোন পণ্য, কতজন কাস্টমার, প্রত্যেকের কত কেজি, তারিখ। এজেন্ট আগে তালিকা দেখাবে; আপনি **হ্যাঁ** বললেই ৬.২ ও ৬.৩ চালান হবে। দাম ৪.৩-এর ঘোষিত মূল্য; অন্য দাম দেবেন না।

### ৪. মাসিক রিপোর্ট (৩.৮ / ৪.২২)

লিখুন: `সেপ্টেম্বর ২০২৬, বিন …`। আইটেম ধরে ক্রয়, বিক্রি ও স্টক আসবে। বিন না দিলে সব ইম্পোর্টারের এক পাতা।

### ৫. ভুল সেভ

চালান না হওয়া পর্যন্ত ভুল বিল অব এন্ট্রি মুছে আবার সেভ করা যায়।

ঝাপসা, অন্ধকার বা বাঁকা ছবিতে নম্বর/তারিখ ভুল পড়তে পারে। পরিষ্কার স্ক্যান দিন।

### ৬. সেভের পর এক নজর

সেভ হলে ছোট টেবিলে বিল নং, তারিখ, কেজি দেখাবে। স্ক্যানের সাথে প্রায় ১০ সেকেন্ডে মিলিয়ে নিন, যাতে C-85 আর C-88 গুলিয়ে না যায়। পুরো বিল আবার যাচাই করতে বলা হবে না।

### ৭. মাসিক রিপোর্টের বাটন

মাস বললে আগে শুধু যাদের সেই মাসে লেনদেন আছে তাদের তালিকা আসবে। এক পার্টির পাশে **রিপোর্ট জেনারেট** বললে তবেই সেই পার্টির রিপোর্ট ও সার্ভিস বিল তৈরি হবে।

### ৮. মাস্টার রিসেট

এক BIN-এর এক মাস মুছতে মাস বেছে ডিলিট বলুন। কনফার্মেশন মেসেজ কনফার্ম না করা পর্যন্ত কিছু মুছবে না। অন্য মাস থাকবে।

### ৯. ইউজার ড্যাশবোর্ড (osbdsyl.online)

BIN + পিন দিয়ে ঢুকে পিডিএফ আপলোড করুন। অনেক পাতা থাকলে এক পাতা করে আলাদা এন্ট্রি হয়। ৬.১ / ৬.২ / ৬.৩ / রিপোর্ট — মাস বেছে পিডিএফ। আপলোড আপনার কনফার্মের পর খাতায় যায়।

```bash
OPERATOR_PIN=আপনারপিন npm run dashboard
```

### ১০. API

পরে দরকার হলে API-র নাম, https ঠিকানা ও কী-এর এনভির নাম যোগ করা যাবে। কী নিজে লিখবেন না। যোগ করলেই সেই API কল হয় না।
