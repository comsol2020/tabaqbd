# এক পাতা (vat-pages)

একসাথে থাকা ফাইল, জিপ, বা অনেক পাতার পিডিএফ থেকে **এক পাতা করে** ফাইল বানিয়ে ভ্যাট বই এজেন্টের (`vat-books`) ইনবক্সে পাঠায়। মূসক ৬.১ এই এজেন্ট ভরে না। কনফার্মের পর `vat-books` সেই পাতা পড়ে ৬.১-এর বাকি কাজ করে।

## কী দেবেন

- অনেক পাতার একটি পিডিএফ
- কয়েকটি ছবি একসাথে (JPG, PNG, WEBP)
- উপরেরগুলোর একটি জিপ

সাথে ইম্পোর্টারের ১৩ সংখ্যার BIN।

## কী হয়

1. প্রতিটি পাতা আলাদা এক পাতার ফাইল হয়।
2. প্রতিটি পাতা ওয়েবসাইটের ইনবক্সে **অপেক্ষমাণ** থাকে। খাতায় এখনো যায় না।
3. দুই এজেন্ট একসাথে চললে ভ্যাট বই এজেন্টকে বলে দেয় যে পাতাগুলো এসেছে।
4. আপনি কনফার্ম করলে ভ্যাট বই এজেন্ট পাতা পড়ে ৬.১ সেভ করে।

## চালানো

দুই এজেন্ট এক প্রসেসে, একই ডেটা ফোল্ডার:

```bash
VAT_DATA_DIR=/path/to/data npx bdk serve --dir /path/to/tabaqbd
```

ড্যাশবোর্ডও সেই `VAT_DATA_DIR` ব্যবহার করবে। একা চালালে পাতা ইনবক্সে যায়, কিন্তু ভ্যাট এজেন্টকে খবরটা তখনই পৌঁছায় না।
